# Project Statement

## Expense Tracker

The Expense Tracker is a Python-based application designed to help users record, manage, and monitor their expenses. It allows users to add, view, edit, delete, and search expense records.

The application also provides budget management features, allowing users to set monthly budgets for different categories and check their spending status.

The project is developed using a modular structure, separating the expense model, management logic, storage, user interface, and main program into different Python files. This makes the application easier to understand, maintain, and extend.

## Objectives

- Maintain expense records efficiently.
- Track total spending.
- Organize expenses by category.
- Allow users to search and modify expense records.
- Set and monitor category-wise budgets.
- Demonstrate modular programming and object-oriented programming in Python.

## Expected Outcome

The application provides a simple command-line interface through which users can manage their expenses and budgets in an organized manner.

# Expense Tracker

A simple Python-based Expense Tracker for managing expenses, budgets, and spending records using a modular design.

## Features

- Add expenses
- View all expenses
- Edit expenses
- Delete expenses
- Search expenses
- Calculate total spending
- Set category budgets
- Check monthly budget status
- Expense and budget validation
